# Timelock Vault

Billetera de ahorro programado en ETH: el usuario deposita y elige cuándo podrá retirar. Admite bóvedas individuales y compartidas entre dos personas, que requieren la aprobación de ambas para el retiro.

## Estructura

- `contracts/`: contrato inteligente, tests y despliegue en Sepolia.
- `frontend/`: aplicación web.
- `docs/`: whitepaper y documentación del proyecto.
